# RBAC cible

| Rôle | Accès cible |
|---|---|
| Élève | Certifications, formations, actualités, progression, discussions, tickets |
| Student Service | Tout élève + création/édition des parcours types + suivi orientation |
| Responsable formation | Catalogue pédagogique + contenus de formation + suivi des cohortes |
| Community manager | Actualités, contenus éditoriaux, statistiques de visibilité |
| Comptable | Données administratives dédiées, sans accès au contenu pédagogique sensible |
| Support | Tickets, modération, diagnostic technique |
| Directeur | Tableaux de bord globaux + pilotage |
| Admin technique | Infrastructure applicative, comptes, permissions, supervision |
